# FeynCheck: Adaptive Theoretical Knowledge Assessment System

**Academic Project Documentation Repository | Semester 6 – Semester 8**

## 📌 About the Repository

This repository serves as the central documentation archive for **FeynCheck: Adaptive Theoretical Knowledge Assessment System**, developed as part of the academic Minor Project and Final Year Project requirements.

It contains the documents, reports, presentations, research materials, technical specifications, and other project-related deliverables prepared and submitted to the college throughout the project lifecycle, from **Semester 6 to Semester 8**.

The repository is intended to maintain an organized record of the project's development, implementation, evaluation, and academic submissions.

## 🎯 About the Project

**FeynCheck** is an adaptive theoretical knowledge assessment system designed to evaluate a learner's understanding of a subject through theoretical questions and answer evaluation.

The project aims to explore a structured approach to assessing conceptual understanding rather than relying exclusively on traditional multiple-choice assessments.

The system focuses on facilitating theoretical assessments, evaluating responses, and supporting a more effective assessment experience.
